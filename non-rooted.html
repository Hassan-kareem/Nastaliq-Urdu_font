🛠️ Step-by-Step Installation Guide

01

Extract Font File

Download the Regular or Kasheeda font package from the links above. Unzip/extract the package using your file manager to find the .ttf font file.

02

Get zFont 3 App

Download and install the zFont 3 Tool App from the Google Play Store on your device.

03

Apply custom font

Open zFont 3, go to the Local tab, click the "+" folder icon, select your extracted .ttf file, and follow the screen instructions for your specific brand to apply the theme.

💡 Pro Tip: Custom font applications vary slightly between Samsung (OneUI), Xiaomi (MIUI/HyperOS), and OnePlus (OxygenOS). If you're stuck, search YouTube for "How to install custom ttf font using zFont 3 on [Your Device Brand Name]" for a visual step-by-step walkthrough.
